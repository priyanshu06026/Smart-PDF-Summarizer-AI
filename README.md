# 📄 PDF Summarizer AI

An AI-powered web application that generates concise and meaningful summaries from PDF documents. Users can upload research papers, reports, notes, or articles and receive instant summaries, helping them save time and improve productivity.

---

## 🚀 Features

- 📂 Upload PDF documents
- 🤖 AI-powered text summarization
- ⚡ Fast and responsive user experience
- 📖 Extract key insights from lengthy documents
- 🎯 Generate concise summaries for quick understanding
- 🌐 Modern and intuitive user interface
- 🔒 Secure document processing

---

## 🛠️ Tech Stack

### Frontend
- React.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js

### AI & Processing
- OpenAI API / LLM Integration
- PDF Text Extraction

### Database
- PostgreSQL

---

## 📋 Workflow

1. User uploads a PDF document.
2. Text is extracted from the PDF.
3. Extracted content is preprocessed.
4. AI model analyzes the content.
5. A concise summary is generated.
6. Summary is displayed to the user.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/aashishky2/Summarizer-AI.git
cd Summarizer-AI
```

### Install Dependencies

```bash
npm install
```

### Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
DATABASE_URL=your_database_url
```

### Run Application

```bash
npm run dev
```

Application will start on:

```bash
http://localhost:3000
```
